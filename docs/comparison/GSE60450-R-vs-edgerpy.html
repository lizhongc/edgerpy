How this page is made

Each step's code is a string that its script runs and times, so the code above is exactly what produced the output. pipeline.R runs the R side and writes every object to raw binaries. pipeline.py runs edgerpy on the inputs R wrote and compares each object with the comparison edgerpy's test suite uses: doubles bit for bit, integers and logicals exactly, names, classes and component order. Both plot sets are drawn at 7 × 7 inches, 100 dpi.

edgerpy ports edgeR's v4 pipelines to Python on edgeR's own compiled code. Reference results from edgeR 4.99.16 in R 4.6.1 (2026-06-24), generated 2026-11-24.
